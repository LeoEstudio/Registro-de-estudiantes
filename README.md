# Registro-de-estudiantes
# Este proyecto es una aplicación web CRUD para *Requisitos de Software** que realiza: registro de estudiantes, registro de asignaturas y registro de notas. Utilizando el SQL Editor Supabase, con el fin de guardar los datos registrados anteriormente.
# Pasos para conectar tu database de Supabase a el CRUD:
1. Copia el siguiente codigo y pegalo en un SQL Editor:
   [schema (1).sql](https://github.com/user-attachments/files/33082358/schema.1.sql)
2. Dirigete al Index y pega la KEY ANON y la URL PROJECT de tu base de datos en el apartado "Conexion a Supabase", **Estos datos unicamente quedan guardados en el navegador del usuario, no en el codigo**
